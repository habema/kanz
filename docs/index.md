features:
  - title: View-only main screen
    details: The board, questions, answer reveals, award banners and a leaderboard reveal with spotlights for the top three. Everything on it is driven remotely.
  - title: Host control from any device
    details: /admin opens tiles, judges answers, awards points, switches the screen and plays sounds. /mc gives a co-host a read-only view with every answer.
  - title: Guided first-run setup
    details: An onboarding wizard covers the admin password, name, teams, questions, points, the round schedule and the كنز/كشكول celebrations.
  - title: كنز and كشكول
    details: Mark any question as a كنز (treasure, multiplied points) and add any number of كشكول challenges per category. Each opens with a picture or a video.
  - title: Fair round schedule
    details: An optional schedule pairs two teams per tile, balances play and pick counts, and avoids back-to-back rounds.
  - title: Excel import, offline
    details: Import questions from a simple one-row-per-tile spreadsheet. Once built, it runs with no internet connection.
